📂 Projects

Task Manager (task_manager.py)

A command-line Python application for managing users and tasks. Includes:


User registration and login authentication
Adding, viewing, and editing tasks (assign, due dates, completion status)
Automatic report generation (task completion %, overdue tasks, per-user stats)
Persistent storage via flat files (user.txt, tasks.txt)


Skills shown: Python fundamentals, file I/O, basic authentication logic, data validation, CLI design.

Server Hardening (server_hardening.pdf)

A practical guide demonstrating Linux server hardening techniques to reduce the attack surface and improve system security. The document covers security best 
practices such as disabling unnecessary services, configuring firewall rules, enforcing secure SSH authentication, applying software updates and patches, and 
implementing the Principle of Least Privilege to protect against unauthorized access.

Threat Detection (Threat detection/)

A cybersecurity project focused on identifying suspicious activity and potential security incidents through log analysis and monitoring techniques. The project
demonstrates the use of pattern matching, event correlation, and automated detection logic toidentify anomalies such as repeated failed login attempts, 
brute-force attacks, and other indicators of compromise, helping to support proactive incident response.

Hashing (hashing/)

A Python-based project exploring cryptographic hashing for secure data handling and integrity verification. The implementation demonstrates the use of hashing
algorithms such as SHA-256 to generate fixed-length digests for passwords and files, illustratinghow hashing can be used to protect sensitive information, 
verify file integrity, and prevent plaintext password storage in security-conscious applications.
